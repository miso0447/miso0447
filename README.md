# 🏫 MathClay 중학수학 - 중학교 수학교사를 위한 인터랙티브 교구 랩

> **클레이모피즘(Claymorphism)** 디자인 스타일로 제작된 **중학교 1~3학년 정규 수학 교육과정 전용** 인터랙티브 시뮬레이션 플랫폼입니다.  
> 고등학교/대학 과정을 배제하고, 중학교 교실의 전자칠판 및 학생 1인 1패드 환경에서 즉시 시연 및 수업에 활용할 수 있도록 제작되었습니다.

---

## ✨ 주요 구성 및 특징

1. **중학교 1~3학년 정규 교육과정 100% 매핑**:
   - **중1 과정**: 소인수분해 & 에라토스테네스의 체, 입체도형 회전체와 전개도
   - **중2 과정**: 일차함수 기울기 & 절편 탐구기, 피타고라스 정리(물 채우기 증명), 삼각형 외심/내심 작도기, 두 주사위 확률 실험실
   - **중3 과정**: 삼각비(sin, cos, tan)와 직각삼각형 닮음, 이차함수 포물선과 꼭짓점 이동, 산점도와 상관관계 & 대푯값 저울

2. **클레이모피즘(Claymorphism) 인터페이스**:
   - 다중 음영(Outset Drop Shadow + Inset Highlight)을 통한 푹신한 3D 점토 질감.
   - 직관적인 슬라이더 조작 및 넉넉한 터치 영역(전자칠판 및 태블릿 터치 최적화).

3. **실시간 인터랙티브 수업 교구 2종 내장**:
   - **히어로 랩**: **[중2 함수] 일차함수 $y = ax + b$ 실시간 시각화기** (기울기 $a$, $y$절편 $b$ 슬라이더, $\Delta x, \Delta y$ 기울기 직각삼각형 표시, 교사용 자동 시연 모드).
   - **라이브 샌드박스**: **[중2 확률] 두 개의 주사위 던지기 & 대수의 법칙 실험실** (3D 주사위 굴리기, 눈의 합 2~12 실시간 빈도수 막대그래프, 합 7의 이론적 확률 수렴 관찰).

4. **선생님을 위한 수업 지도 Tip 제공**:
   - 각 교구 실행 시 전자칠판 판서 요령 및 학생 발문 팁 모달창 제공.

## 🚀 로컬 확인 방법

- 탐색기에서 `index.html` 파일을 더블 클릭하면 웹 브라우저(크롬, 엣지 등)에서 바로 열립니다.
- 파이썬으로 로컬 서버를 띄우려면:
  ```bash
  python -m http.server 3000
  ```
  이후 브라우저에서 `http://localhost:3000` 접속.

## ☁️ Vercel 원클릭 배포 가이드

`vercel.json` 설정이 완료되어 있어 별도 빌드 세팅 없이 배포 가능합니다:
1. GitHub 저장소를 만들고 현재 파일들을 푸시합니다:
   ```bash
   git init
   git add .
   git commit -m "feat: MathClay 중학수학 교구 플랫폼 출시"
   git branch -M main
   git remote add origin <깃허브_레포_주소>
   git push -u origin main
   ```
2. [Vercel](https://vercel.com)에서 해당 저장소를 선택 후 **"Deploy"**를 누르면 끝납니다.
